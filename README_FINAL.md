# FounderFlow v6.0 — ML Startup Intelligence

Focused ML project: Idea Analyzer, Financial Planner, Startup Success Prediction, and Model Insights. Risk Assessment, Knowledge Hub, Competitors, and Recommendations modules have been removed.

## Windows CMD

After extracting the archive, use the folder path shown by the extracted archive. Example:

```cmd
cd Downloads
cd FounderFlow_Final_v6
cd FounderFlow
```

Backend terminal:
```cmd
run_backend.cmd
```

Frontend terminal:
```cmd
cd Downloads
cd FounderFlow_Final_v6
cd FounderFlow
run_frontend.cmd
```

Open http://127.0.0.1:5500 and use Ctrl+Shift+R after an upgrade.

The intro animation is 5 seconds.

## v7 additions
- Competitor Benchmark compares one competitor across product differentiation, customer focus, pricing position, differentiation strength and evidence of competitor gaps.
- The result generates a concrete action plan for strengthening the startup's positioning.
- The comparison is structured decision support and does not claim guaranteed competitive superiority.
